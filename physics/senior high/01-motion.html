    #参考系 “两岸猿声啼不住，轻舟已过万重山。”这是李白在《早发白帝城》中写下的名句。诗人在小船上顺流而下，看到山峦一座座靠近自己，感到非常畅快。 但是现在，思考一下：为什么山峦会靠近诗人？山峦没有“脚”，基本不能移动啊？ 我们考虑一个站在岸边不动的路人。他看到诗人在顺流而下，往下游移动，看到山峦不动；诗人便看到山峦和路人一起往上游移动。假如诗人下船上了岸，路人看见诗人不再移动，诗人看到的山峦也不再移动。看来，路人看见诗人在移动非常重要，因为这可以导致诗人所看到的物体运动情况与路人看到的不相同。 从上面的例子可见，“谁看”非常重要。所谓“谁看”，就是指[参考系]。 DEFINITION 参考系 [DEF 参考系][AKA reference frame]指的是被认定不动的物体。 NOTE 一个人看自己总是不动的。在行驶的汽车中，将窗外的景色蒙住，你就会认为自己和汽车是静止的；只有看到了外面的景色，你的大脑才会根据“地面是静止的”这一条件，自动“纠正”对自己静止的认识。因此，我们认定不动的物体，就是“看别人”的那个物体。 DEFINITION 相对静止、相对运动 假如在某一[参考系]中，一个物体是静止的，则称该参考系与该物体[DEF 相对静止]，也称该物体与该参考系相对静止。 假如在某一[参考系]中，一个物体是运动的，则称该参考系与该物体[DEF 相对运动]，也称该物体与该参考系相对运动。 #描述位置 ##位矢$\boldr$ 我们在初中的时候就学过[平面直角坐标系]，知道[平面直角坐标系]中的[点]与[坐标][一一对应]。事实上，在三维空间中，只要建立一个[空间直角坐标系]，该结论依然成立。因此，我们可以利用它来描述一个物体的位置。 这就和我们初中所学的一些物理量不同了。我们在初中学过的[时间]、[压强]、[长度]这些物理量，它们只用一个数就能表示；而这里，一个物体的位置需要用至多三个数，组成一个三元组，也就是[坐标]，才能精确表示。这样一个多元组，就是[矢量]的表示方法之一。 DEFINITION 矢量、标量 [DEF 矢量][AKA vector]是既有大小，又有方向的物理量。矢量在印刷中通常用粗体字母$\bolda,\boldb,\boldA,\boldB$表示。 [DEF 标量][AKA scalar]是只有大小，没有方向的物理量。标量在印刷中通常用普通斜体字母$a,b,A,B$表示。 例如，[时间]、[压强]、[长度]都是[标量]，而我们接下来学习的[位矢]就是[矢量]。 NOTE 即使是在[一维坐标系]中，[矢量]依然不同于[标量]。[矢量]是有方向的，其坐标表示中正负表方向；而[标量]是没有方向的，其坐标表示中正负表大小。在接下来的学习中，你会更深刻地认识到这一点。 EXAMPLE 假想你前面$1\normalm$处有一个点，描述该点的位置。 这里应当以你为[参考系]。 假如以你为原点，以你的正前方为$x$轴正方向建立[一维坐标系]，则该点的位置可以用[矢量]$\boldr=1\normalm$表示。 假如以你为原点，以你的正后方为$x$轴正方向建立[一维坐标系]，则该点的位置可以用[矢量]$\boldr={-1}\normalm$表示。 假如以你为原点，以你的正右方为$x$轴正方向、正前方为$y$轴正方向建立[平面直角坐标系]，则该点的位置可以用[矢量]$\boldr=(0,1\normalm)$表示。 DEFINITION 位矢 [DEF 位矢][AKA position vector]是从[坐标系]原点指向一个点的[矢量]，代表该点的位置。位矢的基本单位为$\normalm$，读作米，常用$\boldr$表示。 DEFINITION 米 $1$[DEF 米][AKA meter / metre]是光在$1/{299,792,458}\normals$内传播的距离。 “米”的定义在这里先给出，但是这是相对论的结论，还有一大段路要走。我们不妨先沿用初中对米的直观感受。 FIGURE /images/physics/senior high/relative position.svg 不同坐标系中，同一个物体[位矢]是可以不同的。如[FIGURE]，$A,B,C$三点在最短长度为$1\normalm$的方格中。 假如以$A$为原点，正右方为$x$轴正方向，正上方为$y$轴正方向建立[平面直角坐标系]，那么$B$的[位矢]$\boldr_{AB}=(2\normalm,{-6\normalm})$，$C$的[位矢]$\boldr_{AC}=(11\normalm,{-11\normalm})$。 假如以$B$为原点，正右方为$x$轴正方向，正上方为$y$轴正方向建立[平面直角坐标系]，那么$A$的[位矢]$\boldr_{BA}=({-2\normalm},6\normalm)$，$C$的[位矢]$\boldr_{BC}=(9\normalm,{-5\normalm})$。 我们还学过一些其他的国际单位，比如“千米”“分米”“厘米”“毫米”等等。事实上，这些单位都是在一个基础上加最多一个前缀而构成的。我们在高中阶段会遇到以下这些前缀。 DEFINITION 国际单位前缀 [DEF 吉][AKA giga-][AKA G]是表示乘以$10^9$的前缀。 [DEF 兆][AKA mega-][AKA M]是表示乘以$10^6$的前缀。 [DEF 千][AKA kilo-][AKA k]是表示乘以$10^3$的前缀。 [DEF 百][AKA hecto-][AKA h]是表示乘以$10^2$的前缀。 [DEF 分][AKA deci-][AKA d]是表示乘以$10^{-1}$的前缀。 [DEF 厘][AKA centi-][AKA c]是表示乘以$10^{-2}$的前缀。 [DEF 毫][AKA milli-][AKA m]是表示乘以$10^{-3}$的前缀。 [DEF 微][AKA micro-][AKA μ]是表示乘以$10^{-6}$的前缀。 [DEF 纳][AKA nano-][AKA n]是表示乘以$10^{-9}$的前缀。 [DEF 皮][AKA pico-][AKA p]是表示乘以$10^{-12}$的前缀。 [DEF 飞][AKA femto-][AKA f]是表示乘以$10^{-15}$的前缀。 [DEF 阿][AKA atto-][AKA a]是表示乘以$10^{-18}$的前缀。 ##位移$\boldx$ [位移]就是[位矢]的变化。我们知道，一个[标量]的变化可以用它的末值减去它的初值来表示，因此，我们希望把它推广到[矢量]上。 FIGURE /images/physics/senior high/displacement.svg 要计算两个矢量的差，我们将这两个[矢量]放到同一个直角坐标系中。如[FIGURE]，$A,B$两点在最短长度为$1\normalm$的方格中。假设一个动点$P$从$A$移动到$B$。 建立如[FIGURE]所示的直角坐标系，正右方为$x$轴，正上方为$y$轴，那么通过数格子的方法，动点向右移动了$9\normalm$，向下移动了$6\normalm$，那么物体的位移就可以表示为$\boldx=(9\normalm,{-6\normalm})$。通过图形不难发现，$9\normalm$就是$B$的横坐标与$A$的横坐标之差，$-6\normalm$就是$B$的纵坐标与$A$的纵坐标之差，很容易证明无论$A,B$的位置在哪里，这个结论都是普适的。 我们刚刚将坐标的每一项都作了差就可以得到[位移]，这就称作[矢量]的减法。由于在图形上，三个[矢量]可以构成一个三角形，我们就称这是[矢量]合成与分解的[DEF 三角形法则]。 DEFINITION 矢量的减法 对两个[矢量]，将他们坐标的每一项分别作差，组合而成新的[矢量]，这个过程就是[DEF 矢量的减法]，得到的[矢量]就是矢量的差。它的符号表示和标量减法一样：对两个[矢量]$\bolda,\boldb$，它们的差就是$\bolda-\boldb$。 DEFINITION 位移 一个点的[DEF 位移][AKA displacement]，指的是同一坐标系下，一个点在两个时刻的[位矢]之差。 类似地，我们还可以定义矢量的加法。 DEFINITION 矢量的加法 对两个[矢量]，将他们坐标的每一项分别求和，组合而成新的[矢量]，这个过程就是[DEF 矢量的加法]，也叫[DEF 矢量的合成]，得到的[矢量]就是矢量的和。它的符号表示和标量加法一样：对两个[矢量]$\bolda,\boldb$，它们的和就是$\bolda+\boldb$。
    一个人驾驶着一辆汽车向前，同时一架飞机从上方飞过，超过了汽车。汽车与飞机都与地面[相对运动]，那么分别以他们为[参考系]，地面的运动情况一样吗？
    不一样。由于飞机超过了汽车，汽车与飞机之间也在[相对运动]，则分别以他们为[参考系]，地面的运动情况也不一样。 由此可见，多个物体可以两两[相对运动]。
